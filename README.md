# Crypto Compass

Public, live long-term cryptocurrency research dashboard.

**Live:** https://crypto-compass.gautam-arora.chatgpt.site

## What it includes

- 100 leading crypto assets with 60-second automatic refresh
- CoinGecko aggregated prices cross-checked with CoinMarketCap
- DefiLlama protocol adoption and TVL
- GoPlus contract security checks
- Market, liquidity, tokenomics, resilience and cycle scoring
- Full-depth reports with valuation, supply, performance and developer data

Research information only. Not financial advice.
